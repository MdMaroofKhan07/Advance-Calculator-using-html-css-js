# Advanced Scientific Calculator

A modern and responsive Scientific Calculator built using **HTML**, **CSS**, and **JavaScript**. This calculator supports basic arithmetic operations, scientific functions, keyboard input, calculation history, and a clean user interface.

## 🚀 Features

### Basic Operations

* Addition (+)
* Subtraction (-)
* Multiplication (*)
* Division (/)
* Percentage (%)
* Decimal calculations

### Scientific Functions

* Sine `sin()`
* Cosine `cos()`
* Tangent `tan()`
* Logarithm `log()`
* Natural Logarithm `ln()`
* Square Root `√()`
* Power Operator `^`
* Pi Constant `π`
* Parentheses `()` Support

### Additional Features

* Real-time Display
* Keyboard Support
* Auto Bracket Completion
* Delete Last Character (DEL)
* Clear All (AC)
* Calculation History
* Clear History Option
* Error Handling
* Responsive Design
* Modern UI with Hover Effects

## 🛠️ Technologies Used

## 📖 Usage

1. Open the project in a web browser.
2. Enter numbers and operators using the mouse or keyboard.
3. Use scientific functions such as:

   * sin(30)
   * cos(60)
   * tan(45)
   * log(100)
   * ln(10)
   * √(81)
4. Press "=" or Enter to view the result.
5. View previous calculations in the History panel.
6. Use "Clear History" to remove all saved calculations.
